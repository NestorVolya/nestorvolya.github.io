devNVS/VPS — персональний сервер для AI і OSINT-автоматизації

DevOps · solo-build · 2025–2026

Два вузли з розділеними ролями: локальна станція для розробки і VPS для сервісів 24/7. Docker Compose, Traefik з TLS, ізоляція проєктів по мережах, PostgreSQL 16 + pgvector як стійке ядро даних. На VPS працюють TCK Bot (HARON), OSINT API + n8n, Vacancy Pipeline, FlowSint, Tasks API.
